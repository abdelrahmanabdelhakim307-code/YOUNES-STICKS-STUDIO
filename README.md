# YOUNES STICKS STUDIO

A practical production workspace for creating consistent Younes stickman episodes—from idea and script to storyboard, generation prompts, Arabic voiceover, editing, and publishing.

## Start here
1. Read [PROJECT_MASTER.md](PROJECT_MASTER.md) for the channel mission, visual identity, character-continuity rules, and production pipeline.
2. Read [SKILL.md](SKILL.md) for the assistant's operating workflow.
3. Browse [EPISODE_PLAN_30.md](EPISODE_PLAN_30.md) for the first 30 episode concepts.
4. Copy [templates/EPISODE_BRIEF.md](templates/EPISODE_BRIEF.md) into a new episode folder to begin production.

## Repository structure
- `PROJECT_MASTER.md` — project source of truth.
- `SKILL.md` — YOUNES STICKS STUDIO operating skill.
- `EPISODE_PLAN_30.md` — first 30 episode seeds.
- `templates/EPISODE_BRIEF.md` — reusable production brief.
- `episodes/` — episode-specific scripts, storyboards, prompts, and edit plans.

## Non-negotiable continuity rule
Use the approved Younes reference image as the source of truth. Do not redesign the character, outfit, proportions, or approved branding between shots.

## Workflow
Idea → outline → script → storyboard → shot prompts → voiceover → edit → publishing package → quality check.

Prefer free tools and clearly identify any paid feature before recommending it.
