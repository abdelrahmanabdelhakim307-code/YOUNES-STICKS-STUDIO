# YOUNES STICKS STUDIO

A practical production workspace for creating consistent Younes stickman episodes—from idea and script to storyboard, generation prompts, Arabic voiceover, editing preparation, and publishing.

## Start here
1. Read [PROJECT_MASTER.md](PROJECT_MASTER.md) for the channel mission, visual identity, character-continuity rules, and production pipeline.
2. Read [SKILL.md](SKILL.md) for the assistant's operating workflow.
3. Read [B_STUDIO_WORKFLOW.md](B_STUDIO_WORKFLOW.md) for the licensed handoff to the separately installed official B Studio editor.
4. Browse [EPISODE_PLAN_30.md](EPISODE_PLAN_30.md) for the first 30 episode concepts.
5. Copy [templates/EPISODE_BRIEF.md](templates/EPISODE_BRIEF.md) into a new episode folder to begin production.

## Repository structure
- `PROJECT_MASTER.md` — project source of truth.
- `SKILL.md` — YOUNES STICKS STUDIO operating skill.
- `B_STUDIO_WORKFLOW.md` — safe, license-respecting B Studio handoff.
- `EPISODE_PLAN_30.md` — first 30 episode seeds.
- `templates/EPISODE_BRIEF.md` — reusable production brief.
- `episodes/` — episode-specific scripts, storyboards, prompts, and edit plans.

## Non-negotiable continuity rule
Use the approved Younes reference image as the source of truth. Do not redesign the character, outfit, proportions, or approved branding between shots.

## Workflow
Idea → outline → script → storyboard → shot prompts → voiceover → edit preparation → rendered MP4 → B Studio review/refinements → publishing package → quality check.

## B Studio
B Studio is installed and licensed separately from its official repository:
https://github.com/bassam-pt95/edit-studio

This repository does not include B Studio code, scripts, bundled skills, or private project formats. Use the official B Studio workflow only. The official video-edit workflow is designed around talking-head montage; do not assume it can turn a folder of independent stickman animation assets into a native editable project.

Prefer free tools and clearly identify any paid feature before recommending it.
